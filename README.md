# ⚡ Codex of Power

Codex of Power is a web project based on **The 48 Laws of Power**.

It is designed as a simple and interactive way to explore different laws of power, human behavior, influence, and strategy.

## 🚀 Live Demo

https://satan-three.vercel.app/

## ✨ Features

* 📖 Explore the 48 Laws of Power
* 🧠 Learn about power and human behavior
* 🎨 Dark and immersive design
* 📱 Responsive interface
* ⚡ Fast React + Vite application
* 🔍 Easy navigation between laws

## 🛠️ Tech Stack

* React
* JavaScript
* Vite
* Tailwind CSS
* React Router

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/shekhalidev-prog/satan.git
```

Go to the project folder:

```bash
cd satan
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
